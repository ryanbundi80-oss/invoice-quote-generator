# InvoiceKit — Invoice & Quote Generator

A clean, no-sign-up web tool for freelancers and small businesses to create invoices and quotes, preview them live, and download PDF documents.

## Features in this starter

- Invoice / quote mode
- Business and client details
- Line items with quantity and unit price
- VAT/tax calculation
- Withholding tax field
- Multiple currencies including KES
- M-Pesa / bank payment details
- Paid / unpaid / draft status
- Live preview
- PDF download
- Local draft saving in the browser

## Setup

```bash
npm install
npm run dev
```

Open the local URL Vite gives you.
